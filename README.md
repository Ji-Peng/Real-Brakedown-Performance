# Real Brakedown Performance

This repository contains the reference implementation and performance work for the Real Brakedown Performance project.

## Goal

Implement Brakedown without SIMD intrinsics, then evaluate optimizations inspired by *High-Performance SIMD Software for Spielman Codes in Zero-Knowledge Proofs*. The purpose is to measure the performance of a carefully optimized reference implementation alongside SIMD-optimized implementations, rather than treating the original Brakedown code as the performance baseline.

## Development

Implementation, tests, and benchmark methodology will be added here. Keep benchmark configurations and correctness checks reproducible, and document compiler, hardware, and build settings for reported results.
